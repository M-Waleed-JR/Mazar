# مزار (Mazar) 🏨🗺️
> **دليلك التفاعلي لاستكشاف أفضل الفنادق والوجهات السياحية حول العالم**

---

## 🌟 نظرة عامة
**مزار (Mazar)** هي منصة ويب تفاعلية حديثة تتيح للمستخدمين استكشاف والبحث عن الفنادق في مختلف دول العالم عبر خريطة تفاعلية مدعومة بـ **Leaflet** و **OpenStreetMap**.

---

## 🚀 المميزات الرئيسية
- 🔍 **بحث ذكي وموحد:** يدعم الإكمال التلقائي الفوري (Live Autocomplete) وقائمة منسدلة للدول برمزها الدولي.
- ⚡ **وجهات شائعة سريعة:** إمكانية الانتقال المباشر لأشهر الدول (مثل مصر، ألمانيا، السلفادور) بنقرة واحدة.
- 📍 **بطاقات فنادق مخصصة:** عند النقر على أي علامة في الخريطة، تظهر بطاقة فندقية غنية بالمعلومات:
  - اسم الفندق وتقييم النجوم ⭐⭐⭐⭐⭐.
  - الموقع الدقيق داخل المدينة (مثلاً: الإسكندرية - سيدي بشر).
  - رقم هاتف للتواصل مع زر اتصال سريع مباشر.
  - سعر الإقامة التقديري.
- 🎨 **تصميم عصري (Glassmorphism):** واجهة زجاجية شبه شفافة وأنيقة تدعم اللغة العربية بالكامل (RTL) مع خطوط Google Cairo و Montserrat.
- 🆓 **مجاني ومفتوح المصدر 100%:** بدون قيود Google Maps أو علامات مائية.

---

## 🛠️ التقنيات المستخدمة
- **HTML5 & CSS3** (واجهات متجاوبة + Glassmorphism + Flexbox/Grid)
- **JavaScript (ES6+)** (تفاعل ديناميكي، Fetch API، إدارة الكاش والفلترة)
- **Leaflet.js & OpenStreetMap** (نظام الخرائط والعلامات)
- **SweetAlert2** (التنبيهات العصرية)
- **GeoDB & Hotels API (RapidAPI)** (بيانات الدول والفنادق)

---

## 💻 التشغيل
افتح ملف `index.html` في أي متصفح حديث، أو استخدم إضافة **Live Server** في VS Code.
